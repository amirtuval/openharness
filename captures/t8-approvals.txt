--- another tab sees and clears the prompt ---
Two tabs on the same session both draw the approval prompt. "Allow once" in one tab:
tab 2's prompt disappears and the call line reads "done · Allowed once"
(captures/t8-approval-prompt.png, captures/t8-second-tab-cleared.png)

--- kill the server right after a confirmation is stored -> another start resumes the turn ---
:3004, Postgres. The confirmation POST returns, then the server is SIGKILLed. The DB holds:
  1 user.message, 2 status_running, 3 span start, 4 event_start, 5 span end, 6 usage,
  7 agent.tool_use, 8 status_idle(requires_action), 9 user.tool_confirmation, 10 status_running
Restart -> the turn resumes (no stranding): the approved-but-unfinished call is answered
  11 agent.tool_result err=true "Tool web_fetch: execution lost. The turn that started this
     call did not finish, so it was not run again."
and the model carries on (a fresh call, its own pause). The tool is never re-run.
