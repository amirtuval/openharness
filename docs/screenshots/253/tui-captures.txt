Text captures from the manual pass over `oh` (#253), against a local server with a real OpenAI
key. Captured with `tmux capture-pane` at 100x30 (the chat) and plain stdout (the commands).

## `oh modes` — the modes and what each resolves to

    $ oh --server http://localhost:3000 modes
    smart                                                             openai/gpt-5-mini · high
    fast                                                              openai/gpt-5-nano · low
    deep                                                              openai/gpt-5-mini
    mine                                                              my default model
    no-key                                                            anthropic/claude-sonnet-5

Each name is padded to the protocol's longest name (`MODE_NAME_MAX_LENGTH`) and the second
column is what the mode resolves to — its model (or "my default model") and its effort, when it
carries one.

## `--mode` beside `--model` is a usage error

    $ oh --server http://localhost:3000 --mode mine --model openai/gpt-5-nano
    oh: use either --model or --mode, not both: a chat follows a model or a mode.

An unknown mode name is refused with the modes the account has (covered by
`apps/tui/src/chat/target.test.ts`: `no mode matches 'nope'. This account has: smart, mine,
no-key. Run 'oh modes' to list them.`).
